## Answer-writing conventions
- Every answer begins with the question.
- Use plain-text formulas and simple, technically correct English.
- Explain the state-space tree, choices, constraints and pruning.
- For Branch-and-Bound, identify the bound, live nodes, selected node and pruned nodes.
- Show numerical working and verify the final solution.
- Do not confuse Backtracking with Branch-and-Bound.
