## Answer-writing conventions
- Every answer begins with the question.
- Use simple technical English and plain-text formulas suitable for MS Word.
- Keep amortized analysis distinct from average-case analysis.
- For counter and stack questions, show actual cost, total cost and amortized cost.
- For embedded-system questions, justify the choice using timing, memory, energy, data size and predictability.
- For approximation algorithms, define the performance ratio and state whether the problem is minimization or maximization.
- Clearly label assumptions in the Cutting Stock case study.
