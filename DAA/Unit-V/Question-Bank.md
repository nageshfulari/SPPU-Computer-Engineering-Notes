## Practice guidance
- For binary counter questions, show the number of flips for each bit and sum the geometric series.
- For stack questions, explain why each element can be pushed once and popped once.
- For complexity-class questions, distinguish P, NP, NP-hard and NP-complete carefully.
- For randomized Quick Sort, state both expected and worst-case complexity.
- For approximation algorithms, write separate performance-ratio formulas for minimization and maximization.
- For embedded sorting, justify the algorithm against timing, memory, power and stability requirements.
- For Cutting Stock, show a feasible cutting pattern and verify all demands and waste.
