## Answer-writing conventions
- Start every answer with the question.
- Use plain-text formulas and readable pseudocode.
- For multithreaded algorithms, distinguish work, span, parallelism and speedup.
- Explain race conditions with shared data and synchronization.
- For distributed algorithms, state the communication and graph assumptions.
- For string matching, show alignment/comparison steps when required.
- For Rabin–Karp, explain rolling hash, hash collisions and spurious hits.
- Do not claim that string matching alone proves plagiarism.
