## Study and contribution conventions

- Answers are written in clear, technically accurate English and sized according to the marks.
- Diagrams should render inline in GitHub Markdown (Mermaid where suitable) or use image files referenced by relative paths.
- PYQ frequency is counted by paper, not by repeated mentions within a single paper.
- Exact repeats, concept repeats, and broader topic repeats are distinguished.
- The official syllabus defines the exam-preparation boundary. Supplementary explanations should be identified clearly.
