## Diagram conventions
- Use-case names are shown in oval shapes.
- Actors are outside the system boundary.
- Dashed arrows labelled `<<include>>` point from the base use case to the included use case.
- Dashed arrows labelled `<<extend>>` point from the extending use case to the base use case.
- Diagrams are kept compact so their essential structure can be reproduced in an examination.

**Note:** Mermaid flowcharts are used for GitHub-native rendering of use-case layouts. The diagrams preserve the intended relationships and labels, while the written answers explain their UML meaning.
