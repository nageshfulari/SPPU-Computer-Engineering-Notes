## Study Order
1. Prepare Architectural Styles, External Control and Global Resource Handling.
2. Revise data storage, reuse planning and transformation approaches.
3. Study subsystem decomposition, allocation and communication.
4. Practice Component and Deployment Diagram concepts.
5. Practice ATM Deployment Diagram and ATM System Architecture.
6. Revise lower-frequency topics as well; low frequency does not mean unimportant.
