## Topic Groups
1. **Architectural organization and control:** Architectural styles, external/internal control, batch and continuous transformation.
2. **Resource and data management:** Global resources, data storage and reuse plan.
3. **Subsystem design:** Decomposition, allocation and communication.
4. **System design considerations:** Performance estimation, system design activities, interactive interface, dynamic simulation, real-time systems and transaction manager.
5. **UML architecture diagrams:** Component Diagram, Deployment Diagram, ATM deployment and ATM architecture.

## Priority Interpretation
- **Very High:** Architectural Styles (6/6), External Control categories (6/6), Global Resource Handling (4/6).
- **High:** Data Storage Management, Reuse Plan, Batch/Continuous Transformation, subsystem decomposition/allocation and ATM Architecture (3/6 each).
- **Medium:** Component Diagram, Deployment Diagram concepts, ATM Deployment Diagram and four system concepts (2/6 each).
- **Low:** External vs Internal Control, subsystem communication, System Design example and Performance Estimation (1/6 each).

Low frequency does not mean a question can be skipped; the subsystem communication question carries 7 marks.
