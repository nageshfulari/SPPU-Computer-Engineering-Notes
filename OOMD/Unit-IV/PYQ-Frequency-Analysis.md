## 4. Preparation Recommendations
1. Prepare Architectural Styles, External Control categories and Global Resource Handling thoroughly.
2. Revise data storage, reuse, transformation and subsystem design.
3. Practice ATM Architecture and ATM Deployment Diagram.
4. Learn Component and Deployment Diagram notation.
5. Do not omit one-time questions solely because of frequency; some carry 7 marks.

## 5. Evidence Limitation
This file records the supplied frequency metadata. The six original papers were not re-audited question-by-question for this Unit IV package, so no session-by-session occurrence claims are made here. Frequencies are descriptive observations, not predictions or guarantees.
