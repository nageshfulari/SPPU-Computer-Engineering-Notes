# Unit III – Test Case Design Techniques

**Subject:** Software Testing and Quality Assurance (410245-D)  
**Programme:** Fourth Year Computer Engineering (2019 Pattern), SPPU  
**Teaching Hours:** 07 | **Course Outcome:** CO3

## Syllabus coverage

1. **Software Testing Methodologies:** White Box Testing, Black Box Testing, Grey Box Testing.
2. **Static Techniques:** Informal Reviews, Walkthroughs, Technical Reviews, Inspection.
3. **Dynamic Techniques:**
   - Structural: Statement, Branch, Path, Conditional and Loop Coverage.
   - Black Box: Boundary Value Analysis, Equivalence Class Partitioning, State Transition, Cause Effect Graph, Decision Table and Use Case Testing.
   - Experienced-Based: Error Guessing and Exploratory Testing.
4. **Functional Testing:** Unit, Integration, System, User Acceptance, Sanity, Smoke, Regression and Retesting.
5. **Non-Functional Testing:** Performance, Memory, Scalability, Compatibility, Security, Cookies, Session, Recovery, Installation, Adhoc, Risk-Based, I18N, L10N and Compliance Testing.
6. **Exemplars:** Manual Testing – Online Marketing Software Platform; Decision Table Testing – online transfer to an already added and approved account.
