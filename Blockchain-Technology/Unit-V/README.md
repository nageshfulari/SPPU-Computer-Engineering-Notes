## Key technical distinctions
- Ethereum currently uses Proof of Stake.
- EVM bytecode is executed by the EVM; ABI describes external contract interaction.
- EVM memory is temporary; contract storage is persistent.
- Gas measures computational effort; Gwei is a denomination of ETH.
- Swarm is associated with decentralized storage and content distribution.
- Whisper is a historical Ethereum messaging protocol design, not the current core Ethereum messaging service.
