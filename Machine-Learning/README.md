## Answer-Writing Conventions

- Answers are prepared according to the SPPU examination pattern and marks.
- Use simple, technically correct, exam-writeable English.
- Preserve the original question wording, marks, PYQ frequency and priority wherever available.
- Use Microsoft Word-compatible plain-text formulas; do not use LaTeX.
- Draw simple, clearly labelled diagrams that can be reproduced by hand in the examination.
- Include worked examples, algorithms, tables and conclusions wherever relevant.
- Keep complete answers separate from quick revision notes and question-bank analysis.

## Standard Unit Folder Structure

Each unit will follow the structure used in the DAA notes:

- `README.md` — syllabus coverage and unit navigation.
